## Antoune Systèmes

Développement sur mesure pour les PME, les associations et les indépendants, depuis Benet (Vendée), aux portes du Marais poitevin.

- **Logiciels métier** : adhérents, stocks, plannings, devis, espace client.
- **Automatisation et IA** : saisies, relances et rapports automatisés (n8n), IA qui tourne chez le client.
- **Sites web et applications mobiles** : vitrine, refonte, iOS et Android depuis une seule base (React Native, Expo).
- **Déploiement et auto-hébergement** : Docker, Proxmox, Coolify, sauvegardes et supervision.

Tout commence par un rendez-vous dans vos locaux, pour comprendre votre organisation avant d'écrire la moindre ligne de code.

**Réalisations** : Famiam, Écho de Légende, Kadôfamille, SyncTracks, [SystemdManager](https://github.com/Sebdev43/SystemdManager). Détails sur [antoune.fr](https://antoune.fr/#realisations).
